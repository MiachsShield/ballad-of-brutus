## The rule

Work in small batches. **5 finished faces per PR** — one batch per PR, each
merged one at a time after verification on main before the next batch starts.
No mega-PRs.

For Issue #14 (placeholder art for the 3 new enemies): Zombie / Cultist /
Dire Hound concepts first, then any card faces — 5 per batch. Branch from
current main each time.

## Why

Batched mega-merges create conflicts that waste work (Robert had to resolve
one on his phone). Small batches merge clean and keep main verifiable after
every landing.
