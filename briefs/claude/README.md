# Claude — world / canon / design

Standing lane: worldbuilding, canon consistency, game design, balance,
readability audits of card art.

Entry points: `canon/` (decisions are binding), `briefs/claude/` (work queue).
Output: `work/claude/<slug>/` on branch `claude/<slug>`, with DONE.md.

Standing rules:

- Narrative and canon authorship stay Robert's: propose, don't canonize.
  Flag contradictions; never resolve them silently.
- Card-art audits use the readability standard: a card's effect must be
  understandable from the face alone.
- Energy costs stay on Brutus's 20-point bar; do not rescale.
- Second Wind displays only while stunned (settled 2026-09-14).
- Lose = Brutus dies; win = absorb all guilds via formal guild war.
- Real-time dungeon combat is canonical (supersedes the old dice-roll design).
