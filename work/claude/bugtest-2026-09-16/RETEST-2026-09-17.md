## Still broken

**1. Faces still don't show when the build runs from `builds/`, which is
how the repo stores it.** The new fallback is right in principle (on
error, retry with `../art/...`), but the next hand render undoes it:
1. `setCardFace()` compares the image's current src (`../art/...`) with
   `cardFaceUrl()` (`art/...`).
2. They differ, so it resets the src to `art/...`.
3. That fails again. The fallback flag is already set, so the path goes
   into `cardFaceFailed` and the face is hidden for the rest of the dive.

Result: all four hand faces at 0px, `display:none`. The same build opened
from the repo root shows them (784px). Fix: remember the working prefix
once the fallback succeeds (e.g. `cardFacePrefix = "../"`) and build every
URL from it, or have `setCardFace` accept either path as "same".

**2. Consequence lines still print before the hit that causes them.** Two
examples, where the first two lines come before the hit they depend on:
- *"Brutus uses Heavy Blow."* → *"Skulker hits the wall — 12 more"* →
  *"Brutus's Heavy Blow lands for 18."*
- *"Skulker's energy gives out — stunned!"* → *"hits the wall"* → *"Brutus
  punishes the stun — Smite for 14"*.

Wall hits and energy-out stuns should print after the "lands" line.
Cosmetic, but it's the same class of bug as K4.
